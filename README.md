# TCS Chatbot REST API

A Retrieval-Augmented Generation (RAG) chatbot built using Flask, LangChain, FAISS, Hugging Face Embeddings, and FLAN-T5.

## Overview

This project provides a REST API chatbot that answers questions based on information retrieved from a PDF document. It uses FAISS for document similarity search and a Hugging Face language model for generating responses.

## Features

- REST API using Flask
- PDF document processing
- Text retrieval using FAISS vector database
- Semantic search using Hugging Face embeddings
- AI-generated answers using FLAN-T5
- Context-based question answering

## Technologies Used

- Python
- Flask
- LangChain
- FAISS
- Hugging Face Transformers
- Sentence Transformers

## How It Works

1. User sends a question through the REST API.
2. The question is converted into embeddings.
3. FAISS searches the most relevant document chunks.
4. Retrieved context is sent to the language model.
5. The chatbot generates an answer.

## API Endpoint

### POST `/tcs`

Request:

```json
{
    "tcs_question": "What is TCS?"
}
```

Response:

```json
{
    "gpt_response": "Answer generated by the chatbot"
}
```

## Running the Application

Install required packages:

```bash
pip install -r requirements.txt
```

Run the Flask application:

```bash
python app.py
```

The API will run at:

```
http://127.0.0.1:5000
```
